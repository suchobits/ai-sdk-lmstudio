# Changelog

## 0.1.0 (2026-05-08)

Initial release.

- `LanguageModelV1` implementation for LM Studio chat completions
- `EmbeddingModelV1` implementation for LM Studio embeddings
- Streaming with token usage tracking via `stream_options`
- Tool / function calling support
- Structured output (JSON mode and JSON schema)
- `createLmstudio()` factory and `lmstudio` default instance
